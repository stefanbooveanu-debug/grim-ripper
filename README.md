# grim_drip

Grim Dropper — HackTM red-teaming tool.

| Path | Description |
|------|-------------|
| *(root)* | Next.js app (existing) |
| `frontend-stefan/` | React + Vite UI — auth, PowerShell builder, console (Python API), logs, demo game + reference backend |

## frontend-stefan

```bash
cd frontend-stefan
cp .env.example .env
npm install
npm run dev
```

Open http://127.0.0.1:5173/auth

## Root Next.js app

```bash
npm install
npm run dev
```

Open http://localhost:3000
